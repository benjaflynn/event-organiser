# Event Organiser

This app is designed to let a user, after registering their account and logging in, create and view events in order to help organise them.
The user is additionally able to edit and delete existing events.

## How to use

Upon forking the repo, in the root directory run `npm install` and `npm run dev`. If it doesn't open immediately in the browser follow VITE's instructions in the terminal.

A guide on how to register is available on the main page, and upon registering and logging in a further guide on how to create and manage events is available under `Help`.
